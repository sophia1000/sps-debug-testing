SPS debug cell pixel map reference
==================================

Coordinate convention
- Rows below are 1-based top-to-bottom: Row 01 is y=0, Row 16 is y=15.
- Pixels are 1-based left-to-right: P01 is x=0, P16 is x=15.
- Each SPS cell is 16x16 pixels. Linear index = y * 16 + x.
- Payload index = linear index - 16 for rows after the top header.
- Header/magic checks run before payload checks. Bottom row header values are real data, not blank.
- The dictionary cell at cell index -1 is separate and is not shown here.

Important correction
- Socket/orifice row 16 P02-P11 stores world/forward/up/scale header data.
- Plug/penetrator row 15 P01-P16 stores resolver radius samples.
- Plug/penetrator row 16 P02-P11 stores world/forward/up/scale header data.
- Plug/penetrator rows 07 P06 through 13 P16, and row 14 P09-P16, are explicit resolver zero gap pixels, not unclassified unknowns.

ORIFICE / SOCKET CELL (SPS_PRODUCT_SOCKET = 1)
----------------------------------------------
Row 01 (y=0)
  P01 [x=0, y=0, index 0] = MAGIC TL - Cell magic corner 0: SPS_CELL_MAGIC_0 = float4(1,0,0,1).
  P02 [x=1, y=0, index 1] = VENDOR - Header vendor uint. SPS writes SPS_VENDOR_SPS = 1.
  P03 [x=2, y=0, index 2] = PRODUCT - Header product uint. Socket/orifice = 1, plug/resolver/penetrator = 2.
  P04 [x=3, y=0, index 3] = VERSION - Header version uint. SPS_VERSION_SPS = 1.
  P05 [x=4, y=0, index 4] = UNIQUE ID - Header unique id uint for this SPS instance.
  P06 [x=5, y=0, index 5] = PLAYER ID - Header player id uint. 0 if not player-specific.
  P07 [x=6, y=0, index 6] = DEBUG RGBA - Header debug raw rgba. Socket writes 0; resolver writes input.debug.
